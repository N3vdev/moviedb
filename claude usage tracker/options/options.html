How this works

Usage is fetched directly from claude.ai's own usage API (claude.ai/api/organizations/<org>/usage) using your existing claude.ai session — the same data its own Settings → Usage page shows. No manual configuration, no local guessing. It refreshes automatically every 5 minutes, or on demand with the button above or in the popup. Nothing is ever sent anywhere else.
